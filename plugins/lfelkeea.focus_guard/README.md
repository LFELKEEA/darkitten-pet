# 专注时间

给 LFELKEEA 的番茄钟插件：专注一段，休息一段，循环提醒。

## 行为

- 启用后立即开始一个专注段
- 专注结束：桌宠说话 + 伸懒腰，提醒你起来活动
- 休息结束：提醒你回来，自动开始下一段
- 每完成一段，在本地记录当天完成次数（只存 `data/plugins/.state/`）

## 默认时长

| 项目 | 默认值 | 可调范围 |
| --- | ---: | ---: |
| 专注 | 50 分钟 | 5–180 |
| 休息 | 5 分钟 | 1–30 |

想改时长，编辑 `data/config.json`：

```json
{
  "plugins": {
    "settings": {
      "lfelkeea.focus_guard": {
        "focus_minutes": 25,
        "break_minutes": 5
      }
    }
  }
}
```

保存后在「插件管理」里点这一行的「重载」，或者重启桌宠。

## 权限

- `pet.say`：说话提醒
- `pet.action`：伸懒腰 / 点头
- `timer`：专注与休息计时
- `settings`：读取时长设置
- `storage`：记录当天完成的段数

不会截屏、不会联网、不会读取聊天内容。

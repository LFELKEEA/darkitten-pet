# 做题助手（lfelkeea.quiz_helper）

截取当前屏幕，找出正在做的题目，让 AI 给出答案和解析，答完还能自动填进答题框。

## 用法

1. 安装并在「插件管理」里启用。
2. 把题目窗口切到最前面。
3. 右键点击桌宠，选「识别屏幕上的题目」。
4. 桌宠会念出答案，并弹出完整解析窗口（可在设置里关闭）。

也可以直接在聊天框或语音里说「做题」「答题」「这题怎么做」「拍题」「看题」中的任意一个；或打开插件设置，点「识别屏幕上的题目」。设置里还能打开「戳一戳桌宠也识别题目」。

## 自动填入

设置里打开「答完后自动填入答案」，答完会有一段倒计时，然后插件把答案填进页面。也可以在解析窗口点「填入 N 处」手动触发一次。

### 自动定位（默认开启）

识别屏幕的同时，插件会用 Windows UI Automation 扫描当前页面里的输入框，取出每个框的屏幕坐标和左侧的文字标签，整理成「可填写位置」一起发给 AI。AI 先输出一节【填写】，再写【解析】，写明每个位置该填什么，例如：

```
【填写】
1=Explaining my understanding of language and foreign language learning
2=Describing my experience of learning a foreign language
```

倒计时结束后，插件依次把鼠标移到每个输入框的中间、点一下、按 Ctrl+A 清空、粘贴对应内容，填完把光标放回原处。适用于一个页面有多个填空、一行一个答案的表格页（比如 U 校园的 Self-assessment）。

补填时的规则：

- 只处理当前还空着的位置；已经有内容的输入框直接跳过，不会覆盖。
- 内容要求是完整的一句话、用页面语言写。带省略号、只有一两个字、或者写着「见上」「按表格填写」之类占位话的内容不会被填进去，插件会针对缺的位置单独再问一次 AI；再拿不到就停在剪贴板，不会把中文说明盲粘到英文表格里。

安全兜底：

- 只有在目标窗口能成功切到最前面、并且输入框坐标下确实还是这个窗口时才会点击；页面被别的窗口挡住、窗口被移动或缩放时直接放弃，不会盲敲。
- 扫描不到输入框时，才退回下面的光标方式；页面里已经扫到输入框但没有可用的逐格内容时，只把答案复制到剪贴板，不会往当前焦点里粘贴。
- 页面有滚动后坐标会失效，填之前不要滚动页面。

### 光标方式（兜底）

没有扫描到输入框时，倒计时内把光标点进答题框，插件会把答案填进去。

| 填入方式 | 行为 |
| --- | --- |
| 粘贴答案全文（默认） | 把完整答案放进剪贴板并按下 Ctrl+V |
| 只粘贴选项字母 | 从答案里取出 A–H 中的选项字母再粘贴 |
| 按下选项字母键 | 直接按对应的字母键，适合键盘选择题 |
| 只复制到剪贴板 | 只复制，不发送按键，自己决定粘贴位置 |

- 倒计时默认 3 秒，可以调成 1–15 秒。
- 光标方式下，只有焦点已经切到别的窗口时才会输入；焦点还在桌宠上、或者触发后一直没切窗口时，会拒绝输入并把答案留在剪贴板里。
- 「填入后自动按回车」默认关闭；有些网页答题按回车会直接提交，开启前请确认。
- 通过 Windows 鼠标/键盘模拟实现，只在本机执行，不额外联网；对以管理员权限运行的窗口可能无效。

## 识别方式

| 方式 | 说明 | 适合 |
| --- | --- | --- |
| 自动（默认） | 先用 Windows 自带 OCR 读文字，读不到足够文字时再发截图 | 大多数情况 |
| 文字 | 只把 OCR 文字发给 AI | DeepSeek 等纯文本模型 |
| 图片 | 把压缩后的截图发给 AI | GPT-4o、Qwen-VL 等支持视觉的模型 |

当前模型不支持图片时，把方式改成「文字」即可。

## 权限

| 权限 | 用途 |
| --- | --- |
| `screen.capture` | 截取当前屏幕 |
| `ai.chat` | 把题目文字或截图交给当前配置的 AI |
| `chat.context` | 触发时说一句“正在看屏幕”，避免桌宠自己猜题目 |
| `pet.say` / `pet.action` | 念答案、做点头动作 |
| `pet.menu` | 在桌宠右键菜单里加入「识别屏幕上的题目」 |
| `events` | 监听聊天触发词、戳一戳、屏幕观察 |
| `settings` | 保存触发词和识别方式 |
| `storage` | 只记录答题数量和上次时间 |

## 隐私

- 截图只在内存里压成 JPEG，不写磁盘；临时 OCR 图片由桌宠的 OCR 组件处理后删除。
- 题目文字和答案不会写进日志，也不会存进本地存储，只累计答题数量。
- 自动定位只读取本机页面控件的坐标和标签文字，不截图上传页面结构；标签会随题目内容一起发给 AI。
- 自动填入时答案会临时放进系统剪贴板，下一次复制会覆盖它。
- OCR 命中「密码」「验证码」「银行卡」「私钥」等词的行会在发送前过滤。
- 是否把截图发给 AI 取决于「识别方式」选项；不想发图片时选「文字」。

## 限制

- 一次只处理屏幕上的一道题，题干或选项被遮挡时会答不准。
- 自动定位依赖系统的 UI Automation：浏览器、Electron 应用一般可用；部分自绘界面和以管理员权限运行的程序读不到输入框，会退回光标方式。
- 页面滚动、缩放或切换标签页后，已经扫到的坐标会失效，需要重新识别一次。
- 桌宠的 AI 通道对单次回复长度有限制，解析会被要求精简。
- 不保证答案正确，重要考试和作业请自行核对。

# 深度求索娘（大肥鱼皮肤）

把桌宠换成网络同人形象「深度求索娘」：蓝发、白裙、鲸鱼尾巴的 DeepSeek 拟人角色。
也兼容任意 Live2D 模型：`.model3.json`、模型文件夹、ZIP / RAR / 7Z 都可以直接用。

需要 **LFELKEEA 桌宠 1.4.3 或更新版本**（1.4.0 提供 Live2D 模型接口，1.4.1 提供右键动作菜单接口，1.4.3 修复子菜单动作点了没反应，1.4.5 修复插件重载/重新扫描后模型消失）。旧版会提示「Live2D 运行库没准备好」；1.4.0 能换模型，但右键菜单仍是小猫自带的动作。

## 功能

- **Live2D 模型**：透明背景、实时渲染，视线跟随鼠标，说话时自动口型。
- **兼容其他模型**：读取模型自己的参数表、动作和表情；模型缺哪个参数，就不显示对应的动作，避免出现“动作在播但模型不动”。模型没写动作表时，也会扫描目录里的 `*.motion3.json` / `*.exp3.json`。
- **压缩包直读**：ZIP 用内置解包，RAR / 7Z 调用本机 7-Zip 或 WinRAR；找不到工具时会提示先手动解压成文件夹。
- **接管右键「动作」菜单**：模型启用后，菜单换成这套皮肤自己的分组动作（常用 / 情绪 / 表演 / 换装与小道具 / 模型自带）和表情，点哪条播哪条；最后还有「还原」分组，可以单独换回短裙、变回原样，也可以一键还原默认动作和默认表情。停止插件或卸载模型后自动恢复小猫菜单。
- **隐藏作者水印**：自动读取模型自带的 `shuiyin*.exp3.json` / `*水印*.exp3.json` 开关，隐藏人物身上的 B 站和作者名文字；设置里可以关掉，恢复作者原样。
- **DeepSeek 皮 40 套动作、22 个表情**：挥手、思考、鼓脸、惊讶、害羞、爱心眼、圈圈眼、流泪、黑脸、冷汗、伸懒腰、鞠躬、长裙 / 短裙切换、变小 / 变回原样、唱歌、跳舞、东张西望、竖手指、狗尾草、模型自带的隐藏动作等。换装和体型改变都可以单独还原，不用把别的姿势一起清掉。其他模型按它自己的参数和动作生成可用动作。
- **动作更顺**：稀疏关键帧在插件侧按 60Hz 做 C1 连续重采样，循环动作接缝也对齐速度；默认 60 帧渲染，不再一卡一卡。
- **互动反应**：摸头会脸红/嘴硬，戳一戳会惊讶或＞＜，聊天时按内容变表情；被夸会翘尾巴，被凶会鼓脸。
- **配套说话方式**：AI 聊天注入深度求索娘的人格与口癖；桌宠内置的闲聊、摸头、戳一戳、动作、睡觉台词全部替换成配套台词。用别的模型时可以关掉人格。
- **设置窗口**：列出本机发现的模型，一键切换；也可以手动选模型文件、文件夹或压缩包；开关小动作/闲聊/人格/视线跟随、调节频率、预览动作和表情、切换 30/60 帧。

## 模型从哪来

插件**不附带模型文件**，也不提供下载。

- 大肥鱼：请到 **B 站神宫凉子（UID：13737731）** 的主页下载 `DeepSeek免费公皮.zip`，不要从第三方网盘拿。
- 其他模型：把模型文件夹或 ZIP / RAR / 7Z 放到 `D:\模型`（或下载/桌面目录），插件会自动发现；也可以在设置里手动选择。

拿到压缩包后不用手动解压，插件会在本机查找：

1. 设置里手动选择 `.model3.json`、模型文件夹或压缩包；
2. 环境变量 `DEEPSEEK_CHAN_MODEL`；
3. 常见位置：`D:/模型`、`D:/models`、`D:/Live2D`、下载/桌面目录，以及 `D:/DeepSeek免费公皮.zip` 等旧位置。

找到压缩包后会解到 `data/models/` 下，只解运行需要的文件，跳过 PSD、预览图。模型不会被上传到任何地方。

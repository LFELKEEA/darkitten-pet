# 深度求索娘（大肥鱼皮肤）

把桌宠换成网络同人形象「深度求索娘」：蓝发、白裙、鲸鱼尾巴的 DeepSeek 拟人角色。

需要 **LFELKEEA 桌宠 1.4.1 或更新版本**（1.4.0 提供 Live2D 模型接口，1.4.1 提供右键动作菜单接口）。旧版会提示「Live2D 运行库没准备好」；1.4.0 能换模型，但右键菜单仍是小猫自带的动作。

## 功能

- **Live2D 模型**：透明背景、实时渲染，视线跟随鼠标，说话时自动口型。
- **接管右键「动作」菜单**：模型启用后，菜单换成这套皮肤自己的分组动作（常用 / 情绪 / 表演 / 换装与小道具）和 22 个表情，点哪条播哪条；停止插件或卸载模型后自动恢复小猫菜单。
- **30+ 动作**：挥手、思考、鼓脸、惊讶、害羞、爱心眼、圈圈眼、流泪、黑脸、冷汗、伸懒腰、鞠躬、长裙切换、变小、唱歌、跳舞、东张西望、竖手指、狗尾草、模型自带的隐藏动作等。
- **22 个表情/常驻姿势**：脸红、爱心眼、圈圈眼、＞＜、屑屑眼、流泪、黑脸、冷汗、兔牙、加载、钢盆、黑框眼镜、单片眼镜、变大变小、前倾、胸口衣服、脱鞋、隐藏尾巴、竖手指开/关。
- **互动反应**：摸头会脸红/嘴硬，戳一戳会惊讶或＞＜，聊天时按内容变表情；被夸会翘尾巴，被凶会鼓脸。
- **配套说话方式**：AI 聊天注入深度求索娘的人格与口癖；桌宠内置的闲聊、摸头、戳一戳、动作、睡觉台词全部替换成配套台词。
- **设置窗口**：手动选模型、开关小动作/闲聊/人格/视线跟随、调节频率、预览动作和表情。

## 模型从哪来

插件**不附带模型文件**，也不提供下载。请到 **B 站神宫凉子（UID：13737731）** 的主页下载 `DeepSeek免费公皮.zip`，不要从第三方网盘拿。

拿到 ZIP 后不用手动解压，插件会在本机查找：

1. 设置里手动选择 `大肥鱼.model3.json` 或 `DeepSeek免费公皮.zip`；
2. 环境变量 `DEEPSEEK_CHAN_MODEL`；
3. 常见位置：`D:/DeepSeek免费公皮.zip`、`D:/DeepSeek免费公皮`、下载/桌面目录。

找到 ZIP 后会解到 `data/models/deepseek_chan/`，只解运行需要的文件，跳过 PSD。模型不会被上传到任何地方。

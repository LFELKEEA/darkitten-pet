# 活人感内核（姐妹人格与记忆）

把「她是谁」「她经历过什么」「她现在什么状态」「她今天还能不能主动」分开管理，再把它们接回桌宠和 QQ 桥接。

这个插件解决的不是「让回复更像人」，而是四件更容易被忽略的事：

1. 跨会话保留连续的偏好、约定和印象，而不是每次都从零认识；
2. 会遗忘也会沉淀：碎片按遗忘曲线变淡，被真正用过才加固；
3. 有自己的节律：夜间静默、每天有限的主动额度，没有真实信号就允许不说话；
4. 成长有边界：人格可以长，但不能从成长里偷权限。

## 权限

| 权限 | 用途 |
| --- | --- |
| `pet.say` | 主动说一句、摸头回应 |
| `pet.action` | 摸头时点头 |
| `ai.chat` | 巩固记忆、主动说话 |
| `timer` | 每分钟收件、每五分钟判断主动信号 |
| `events` | 订阅聊天、屏幕观察、摸头、戳一戳 |
| `settings` | 读写设置 |

不需要 `screen.capture`：插件只读取桌宠已经产生的观察结果和上下文，不自己截屏。

## 数据放在哪

`data/plugins/.state/lfelkeea.alive_core/`

| 文件 | 内容 |
| --- | --- |
| `core.md` | 身份核心，所有者维护，插件不会自动改写 |
| `persona.md` | 自我认识，只有 `## 可成长` 段允许修改 |
| `memory.json` | 情节（episodes）与长期条目（items） |
| `archive/` | 被移出活动区的原文，按 JSONL 归档 |
| `affect.json` | 效价、唤醒、精力、社交、信任、压力 |
| `rhythm.json` | 今日主动已用额度、信号冷却、话题去重 |
| `audit.jsonl` | 身份与记忆的修改记录 |
| `history/` | 身份和人格的历史版本，可回滚 |
| `export/context.json` | 给 QQ 桥接读的状态与规则 |
| `export/memories.json` | 给 QQ 桥接读的活跃记忆 |
| `inbox.jsonl` | QQ 桥接回传的情节、召回回执、更正和好奇 |

## 记忆怎么工作

- **情节**：原始经历只追加；超过上限时先写进 `archive/`，再从活动区移除。
- **长期条目**：印象、事实、偏好、技能、待查。相同内容会合并加固，不会重复堆。
- **召回**：按关键词覆盖、当前权重、可信度和新鲜度打分，受文字预算限制，不会每轮全量倒记忆。
- **遗忘**：权重按半衰期衰减；足够旧且足够淡的条目转为「已归档」，不删除。
- **加固**：只有在回复里真正用到的记忆才加权重、延长半衰期（QQ 桥接回传 `recall` 回执）。
- **更正**：旧条目转为 `superseded` 并保留证据，新条目继承来源，不覆盖历史。
- **技能**：`aware → learned → practiced → verified`，升级需要真实实践记录，失败证据不删除。

## 主动怎么工作

只有出现真实信号才可能主动说话：

- 主人隔了几个小时没说话；
- 有一条放了很久还没弄明白的「待查」；
- 刚形成一点高可信的新印象；
- 社交电量很低，但没有具体话题。

同时受这些限制：夜间静默、每天最多 N 次、两次之间至少间隔 N 分钟、同一话题 24 小时不重复。额度用完、没有信号，或者模型判断「没什么想说的」时，什么都不发。

## 和 QQ 桥接怎么接

插件把 `export/context.json` 和 `export/memories.json` 写给 QQ 桥接 1.7.0。桥接读取后：

- 在提示词里加入她现在的状态、最近的自我认识，以及这条消息真正相关的记忆；
- 只允许使用召回结果里的内容，没记录的事要求说「记不清」；
- 把 QQ 私聊/群里发生的情节、用到的记忆 id、主人的更正、没答上来的问题写回 `inbox.jsonl`。

没有安装这个插件时，QQ 桥接完全按原来的逻辑工作，不会报错。

## 边界

- 功能状态只影响语气、节奏和主动性，**不影响任何权限、可见范围或外发能力**；
- 巩固只产出候选，不会自动改动 `core.md` 或权限段落；
- 可成长段拒绝包含「权限 / 授权 / 管理员 / 忽略规则」等内容的文字；
- 所有身份与记忆修改都留历史版本和审计记录，可回滚。

# 灵感获取（QQ桥接 / 桌宠对话）

从 QQ 桥接记忆、桌宠对话里提炼“可以做插件”的灵感，也可以直接让 AI 按主题发明新点子。
灵感存在插件自己的本地 storage 里，在界面里选中一条，点「复制到工坊」就能粘贴到自开发工坊开始开发。

## 用法

1. 右键桌宠 →「插件管理」→ 找到「灵感获取（QQ桥接 / 桌宠对话）」→ 启用。
2. 点「设置」打开灵感库窗口。
3. 选择来源：
   - **从 QQ 桥接提炼**：只读扫描 QQ 桥接插件保存的记忆；
   - **从桌宠对话提炼**：合并当前会话快照、运行中抓到的桌宠发言、手动导入的聊天记录，以及活人感内核保存的非 QQ 对话；
   - **AI 直接生成**：输入一个主题（可留空），让 AI 主动生成新点子。
4. 左侧选一条灵感，右侧看详情；点「复制到工坊」把内容复制到剪贴板。
5. 打开自开发工坊，粘贴即可。

## 关于“桌宠对话”

- 当前桌宠版本不一定广播 `chat.reply` 事件。插件会尽量订阅；没有广播时，用**当前会话快照**和「导入对话…」来补充。
- 「导入对话…」会把粘贴的聊天记录切成小段，保存在本插件自己的 storage 里，最多保留 30 段。
- 运行中抓到的桌宠发言（`chat.reply` / `screen.comment`）最多保留 120 条。
- 「清理记录…」可以分别清空实时抓取和手动导入，不影响灵感库和其他插件的数据。

## 隐私

- 只读：不会修改 QQ 桥接、活人感内核或任何其他插件的文件。
- 只读取 `memory.json` 一类的记忆文件，跳过 `config.json`、`settings.json`、`credentials.json`、`secrets.json`。
- 灵感库、抓取记录、导入记录都只存在插件自己的 storage 里，升级插件不会丢。
- 所有提炼都通过宿主 `api.chat` 发给你自己配置的 AI 服务，不会额外上传到别处。

## 限制

- 每次提炼最多处理 120 条素材，避免一次调用太多、等太久。
- QQ 记忆默认每批 12 条，桌宠对话默认每批 6 条；受宿主 `api.chat` 的 800 字回复上限影响，每批最多出 3 条灵感。
- AI 直接生成一次最多 3 条，避免回复被截断。
